# 辐射拾荒 · RadScav —— Demo


> 技术：纯 HTML5 + Canvas + 原生 JS，**零依赖、单文件可玩**

---

## 怎么运行（最简单）

1. 进入本文件夹 `demo/`
2. **双击 `index.html`**，浏览器自动打开即玩
3. 方向键 / WASD 移动，收集黄色废料，避开红色辐射区

（无需安装任何东西、无需联网、无需构建）

## 设计意图

| 维度 | 做法 |
| --- | --- |
| 核心循环 | 探索（移动找废料）→ 风险决策（进危险区 vs 保守）→ 回报（分数），60 秒 / 血量归零结束 |
| 风险/收益比 | 废料偏向危险区边缘生成，越冒险收得越多，但掉血；强制玩家做权衡 |
| 体验打磨 | 开始界面一句话讲清循环；血量条按 40/20 阈值变色；危险区透明度随半径加深；结束界面显示得分 + 循环总结；一键重开 |
| AI 辅助开发 | 用 AI 辅助生成与检查代码，我聚焦玩法定义与体验细节（对应岗位"自然语言描述创意、AI 生成代码、人打磨玩法"） |

## 技术栈与结构

```
demo/
├── index.html   # 结构 + 样式 + 开始/结束遮罩
├── core.js      # 纯逻辑层（碰撞 / 危险区增长 / 掉血梯度），可单元测试
├── game.js      # 渲染与交互层（Canvas + 键盘输入 + 游戏循环）
└── test.cjs     # 核心逻辑单元测试（node test.cjs）
```

- 渲染：Canvas 2D，`requestAnimationFrame` 驱动，固定步长防卡顿
- 输入：方向键 / WASD，归一化对角线速度
- 测试：`node test.cjs` 已通过（碰撞、危险区封顶、掉血梯度断言）

## 更新日志

- **v1.1（2026-08-21）新增回血道具**：场上保持 2 个绿色医疗包，拾取 +25 血（封顶 100）；偏向安全区生成，强化"冒险进危险区 → 回安全区补血"的循环，让核心循环的"风险决策"更有层次。
- **v1.2（2026-08-22）本地排行榜系统**：每局结束自动记录成绩到浏览器 `localStorage`（Top 8，含分数 + 日期），开始/结束界面展示榜单，本局进榜高亮；排序逻辑放 `core.js` 并补单元测试。移动速度下调至 2.5（更沉稳走位）。
- **v1.3（2026-08-22）三种增益道具**：蓝=加速（4s 移速 ×1.8）、金=分数翻倍（5s 废料得分 ×2）、紫=辐射中和（危险区瞬间回缩到基础半径）。各自偏向不同区域生成（蓝在安全区外环、金在危险区边缘、紫在危险区内），分别强化机动/收益/威胁三个维度；顶部显示激活状态计时。
- **v1.4（2026-08-22）削弱辐射中和**：紫道具由"复位到基础半径"改为"当前半径减半"，翻盘幅度更克制，避免后期一刀清场破坏难度曲线。
- **v1.5（2026-08-22）负面道具 + 问号随机化**：新增红=陷阱（-25 血）、灰=减速（3s ×0.5）、暗红=中毒（4s 持续掉血）三类负面效果；并把"除血包外的全部效果"（加速/翻倍/中和/陷阱/减速/中毒）合并为一个**问号随机道具**——捡到后从效果池随机获得一种，开盲盒。血包仍为固定绿色 +25 血。顶部三行分别显示增益(蓝)/减益(红)/最近开到的效果(白)。
- **v1.6（2026-08-22）陷阱改为扣分**：陷阱由"瞬扣 25 血"改为"扣除 30 分"（≈3 块普通废料，防负数）。扣分不叠加血线压力、不会致死，惩罚语义更"经济"；配合分数翻倍道具，踩陷阱的成本在翻倍期间更高，决策张力更强。结束界面"收集废料"统计改为取整显示。
- **v1.7（2026-08-22）特殊金色废料**：约 25% 概率刷出金色菱形废料，得分 ×2（20 分，翻倍状态可达 40 分），且 100% 生成在辐射区内部（0.25~0.8×r）——把"高风险高回报"再压进辐射区核心，强化向死而生决策。普通废料生成逻辑不变（55% 边缘 / 45% 全图）。结算"收集废料"改为独立计数显示。
- **v1.8（2026-08-22）问号道具改为全图随机**：问号随机道具不再偏向辐射区边缘生成，改为全图均匀随机（不设区域偏好），开盲盒的机会与风险更平均地散布全图。
- **v1.9（2026-08-22）排行榜分数门槛**：只有得分 ≥300 才计入排行榜（`insertScore` 增加 `minScore` 参数，低于门槛不插入）；未达标时结算显示"未达 300 分，未计入榜单"，达标但没进 Top8 显示"未进榜（榜单已满）"；榜单标题标注"300 分以上"；读取时自动过滤历史低分记录，保持榜单一致。
- **v1.10（2026-08-22）榜单扩容至 Top 10**：排行榜保留条数由 8 提升至 10（`BOARD_MAX=10`），标题与截断逻辑自动联动。
